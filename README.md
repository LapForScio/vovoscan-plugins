# vovoscan-plugins

Community source repository for [vovoscan](https://vovoscan.yieldgrowth.org): rule-based content
sources (JSON manifests) contributed and maintained by the community.

`vovo-plugins-community/` is a self-contained plugin repository: add its `repo.json` link (or a
single `.vovo` manifest) in the app under Sources → + Add. See each source's `README.md` for what
it provides and its known limits.

Official, reviewed sources live in a separate repository; this one is uncurated — a source here
can stop working at any time if the site it reads changes. Pull requests welcome: read the
authoring brief (`docs/AUTHORING.md` in the official repository) before writing a new source.
